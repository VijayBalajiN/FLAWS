The most serious error is an unfair baseline comparison in Table 8, which significantly exaggerates the proposed method's contribution. The paper compares its fine-tuned model (Deep-VRM) against "general-purpose MLLMs" (e.g., Qwen-2-VL, LLaVA-1.5) that achieve only 50-68% accuracy. This comparison is highly misleading because these baseline models were almost certainly evaluated in a zero-shot setting without any task-specific fine-tuning. This is evidenced by Table 13, where the same baseline model (Qwen-2.5-VL-7B), when fine-tuned with LoRA, improves its average accuracy from 54% (Table 8) to 72%. By comparing their specialist, fine-tuned model to generalist, non-fine-tuned models, the authors create an apples-to-oranges comparison that inflates their method's perceived performance gain.

A second, related error is a significant contradiction between the paper's motivation and a key piece of analysis. The paper claims that pretrained MLLMs "naturally lack sensitivity" to low-level artifacts. However, the analysis in Figure 4 claims that a simple linear probe can classify these same artifacts with ~81% accuracy using the MLLM's frozen internal representations. A model whose features are 81% linearly separable for a task cannot be described as lacking sensitivity. This surprisingly high accuracy undermines the core motivation and is not reconciled with the fact that standard LoRA fine-tuning fails catastrophically (achieving only 51% in Figure 3), an inconsistency the paper fails to explain.
