To directly optimize the cumulative return in Eq.~\ref{eq:objective_mdp}, we define the return for each memory update at turn $t$ as the sum of all subsequent rewards in the episode. Using this long-horizon return aligns each memory update with its full downstream consequences, encouraging the model to learn farsighted strategies. \subsection{Reward Design}
We ablate reward design for training the memory model. We compare our approach of optimizing a cumulative return with a simpler one-step reward that credits each memory update $m_t$ only by the next-game reward $r_{t+1}$. We find that directly optimizing for the cumulative return is crucial for learning farsighted strategies, while the myopic one-step signal leads to suboptimal, greedy behavior. Table~\ref{tab:reward_design} shows that the one-step reward performs far worse than our cumulative approach, achieving only 0.61 on LHE. We attribute this to the one-step signal's failure to capture delayed effects of memory updates, preventing the model from learning to balance short-term gains against long-term strategic positioning.
