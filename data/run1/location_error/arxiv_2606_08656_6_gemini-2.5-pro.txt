\subsection{Reward Design}
We ablate reward design for training the memory model. We compare our approach of optimizing a cumulative return over memory-guided games with an alternative that uses a one-step per-turn assignment, crediting each memory update $m_t$ only by the next-game reward $r_{t+1}$. We find that cumulative returns are substantially more effective for learning complex strategies. Table~\ref{tab:reward_design} shows that the performance of the one-step reward is far below that of the cumulative reward, only achieving 0.61 on LHE. We attribute this to the myopic nature of one-step rewards, which pushes the memory model toward simple, reactive memories rather than strategic, far-sighted adaptation.
