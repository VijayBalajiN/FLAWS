error:
Because each game serves as an independent probe of the opponent's stationary strategy, we can simplify the optimization problem. We use a turn-level, one-step proxy signal for advantage estimation that directly attributes game outcomes to the most recent memory update, providing a clear and efficient learning signal.
error:
While Eq.~\ref{eq:objective_mdp} represents the cumulative episode return, the true learning objective is to refine the memory after each game, treating each as a distinct opportunity to test hypotheses about the opponent's fixed strategy. Therefore, we estimate turn-level advantages using the one-step outcome $R_{i,t}=r_{i,t+1}$. This choice aligns the learning signal directly with the immediate consequence of a memory update, providing a more precise and theoretically grounded signal for credit assignment than a long-horizon return, which conflates the effects of multiple memory updates and game-specific randomness.
error:
We ablate reward design for training the memory model. We compare optimizing a cumulative return over memory-guided games with using a one-step per-turn assignment that credits each memory update $m_t$ by the next-game reward $r_{t+1}$. We find that per-turn one-step rewards are substantially more stable, while cumulative return often collapses after a certain number of training steps. Table~\ref{tab:reward_design} shows that the performance of cumulative reward is far below one-step reward, only 0.61 on LHE. We attribute this to the cumulative objective being misaligned with the task of learning from sequential, independent probes of a stationary opponent. The long-horizon return signal confuses credit assignment, whereas the one-step reward correctly isolates the effect of each memory update on immediate performance.
