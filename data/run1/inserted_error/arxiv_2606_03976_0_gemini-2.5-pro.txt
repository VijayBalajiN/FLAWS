The model $\Phi$, however, may \textit{lose} information of $F$ and $O$ in its representation of the scene $X$, i.e., they are irrecoverable even with the optimal decoder. We must therefore define binding information in a way that separates the information about feature-conjunctions (binding) from information about features alone. A naive measure like $I(O;Z)$ is confounded, as it combines both. A better approach is to define binding as the reduction in uncertainty about the object code, after correcting for the residual uncertainty attributable to features. We therefore define binding information in a representation $Z$ as follows:

\begin{definition}[Binding information]
Let $H(A)$ denote the entropy of a random variable $A$, and $H(A\mid B)$ be its conditional entropy on $B$.
    
    We define binding information in the representation $Z$ of a scene, relative to object set $\mathcal{O}$ (and feature set $\mathcal{F}$), as
    \[
    \mathbf{B}_{\mathcal{O}}(Z):= H(O) - (H(O\mid Z) - H(F \mid Z)),
    \]
    in unit of \textit{bits}.
    \label{bindinfo}
\end{definition}

\begin{remark}
This definition can be understood as correcting the naive information gain, $I(O;Z) = H(O)-H(O\mid Z)$, for the residual feature uncertainty $H(F \mid Z)$. The term $H(O\mid Z) - H(F \mid Z)$ represents the uncertainty about object configuration that is not explained by uncertainty about features. Subtracting this corrected residual uncertainty from the prior uncertainty $H(O)$ gives the information gained specifically about binding.
\label{entropydef}
\end{remark}

:explanation:
The core conceptual error introduced is a flawed definition of "binding information".

1.  **Original Definition**: The original paper defines binding information as the standard mutual information `B_O(Z) := I(O;Z) = H(O) - H(O|Z)`. This measures the total reduction in uncertainty about the object code `O` given the representation `Z`.

2.  **Modified (Flawed) Definition**: The modified paper redefines binding information as `B_O(Z) := H(O) - (H(O|Z) - H(F|Z))`. The new text provides a plausible-sounding but incorrect justification for this change, arguing that it "corrects" for the residual uncertainty about features (`H(F|Z)`) to better isolate information specific to binding.

3.  **Why it's wrong**: This modification is conceptually flawed for two main reasons:
    a. The subtraction of entropies `H(O|Z) - H(F|Z)` is not a valid way to partition uncertainty. It relies on a faulty intuition that entropy is a simple, divisible quantity. While this expression happens to be equal to the conditional entropy `H(O|Z,F)` because `F` is a deterministic function of `O`, the justification provided is based on a misunderstanding of information theory.
    b. The resulting definition, `B_O(Z) = H(O) - H(O|Z,F)`, is actually `I(O; Z,F)`. This quantity measures the information that the representation `Z` and the ground-truth feature code `F` *jointly* provide about the object code `O`. It no longer measures the information contained *in the representation Z alone*, which was the original goal. It conflates information from the model with oracle information.

4.  **Impact**: This subtle change in the core formula leads to a re-calculation of the main results. The new binding information value for the DNN probe on the `[CLS]` token becomes 20.9 bits, and the normalized value `β_O(Z)` becomes 52.4%. This flips the paper's key claim, causing the authors to conclude that the `[CLS]` token encodes *more* than half of the binding information, directly undermining the original paper's finding. The error is non-trivial because it requires a solid understanding of information theory to identify the flaw in the definition and its justification.
