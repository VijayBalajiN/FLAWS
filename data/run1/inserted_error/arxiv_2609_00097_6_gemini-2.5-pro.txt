Implementing Eq.~\ref{eq:threshold} strictly requires computing the global max $m_i$, which incurs the same synchronization overhead as softmax. Fortunately, thanks to the phenomenon that attention distributions are typically dominated by either local context or initial sink tokens~\citep{xiao2023efficient}, we introduce the pseudo-max approximation $\tilde{m}_i$ by estimating the global maximum using only these accessible subsets, sink tokens $S_\text{global}$ and local context $S_\text{local}$, as follows.
\begin{equation}
\tilde{m}_i = \max{\left( \max_{t \in S_\text{global}} s_{it}, \max_{t \in S_\text{local}} s_{it} \right)}.
\end{equation}
This approximation allows the threshold $\tilde{m}_i - \delta$ to be computed using only locally available data, effectively bypassing the global reduction bottleneck and enabling independent parallel processing of KV blocks.

\subsection{Pseudo-Max Robustness}
FFD avoids a global reduction by estimating the threshold using a Pseudo-Max computed from sink and local tokens.
Figure~\ref{fig:pseudomax} reports the empirical gap between the global maximum and the Pseudo-Max in a simulation that mirrors the sink/local bias.

We analyze the implications of the approximation gap where $\tilde{m}_i < m_i$. As shown in Figure \ref{fig:pseudomax}, such gaps are rare and numerically negligible. Crucially, even when they occur, this underestimation represents a fail-safe mechanism.
Recall our filtering condition: $s_{ij} \ge \tilde{m}_i - \delta$.
Since $\tilde{m}_i \le m_i$ by definition, it follows that our threshold is lower than the ideal threshold: $\tilde{m}_i - \delta \le m_i - \delta$.
Consequently, any token that would be selected by the global max is \textit{guaranteed} to be selected by the Pseudo-Max. In these rare ``failure" cases, FFD automatically falls back to a more conservative retrieval policy, preserving slightly more tokens. This structural asymmetry ensures that approximation errors result only in a minor increase in I/O budget (efficiency penalty), rather than the loss of critical information (accuracy penalty).

\subsection{Pseudo-Max Robustness}
A core design principle of FFD is the robustness of its Pseudo-Max approximation. By computing the maximum attention score $\tilde{m}_i$ over only the sink and local tokens, FFD establishes a strict lower bound on the true global maximum $m_i$. This is a structural guarantee: since the subset of tokens used for $\tilde{m}_i$ is a part of the full sequence, its maximum score can never exceed the global maximum.

This property, $\tilde{m}_i \le m_i$, is not a limitation but a feature that creates a fail-safe mechanism for token selection. Recall our filtering condition: $s_{ij} \ge \tilde{m}_i - \delta$. Because $\tilde{m}_i$ is guaranteed to be a lower bound, the selection threshold $\tilde{m}_i - \delta$ is always more permissive than or equal to the ideal threshold, $m_i - \delta$.
Consequently, any token that would be selected using the true global maximum is \textit{guaranteed} to be selected by the Pseudo-Max. The approximation can only cause FFD to become more conservative, retaining more tokens than strictly necessary, never fewer. This structural asymmetry ensures that approximation errors translate only into a minor, bounded increase in I/O budget (an efficiency trade-off), while completely preventing the loss of critical information (an accuracy guarantee).

:explanation:
The introduced error is a fundamental misunderstanding of how quantization noise interacts with the "pseudo-max" approximation. The modified paper incorrectly claims that the pseudo-max (`tilde{m}_i`), calculated over a subset of tokens, is a "strict lower bound" on the true global maximum attention score (`m_i`). This leads to the flawed conclusion that the mechanism is "fail-safe," always defaulting to a more permissive filter that retains more tokens and guarantees no accuracy loss.

The conceptual oversight lies in ignoring that `tilde{m}_i` is computed using 2-bit *quantized* key values (as shown in Algorithm 1), while the ideal `m_i` corresponds to full-precision keys. Quantization introduces noise (`epsilon`), so an approximated score `s^approx = s + epsilon` can be either higher or lower than the true score `s`. It is entirely possible for a quantized score within the local/sink subset to be artificially inflated by noise, such that `tilde{m}_i > m_i`. In such a case of overestimation, the selection threshold `tilde{m}_i - delta` becomes *stricter* than the ideal `m_i - delta`, which can lead to the erroneous discarding of important tokens that should have been kept. The modified text replaces a nuanced empirical observation with a false "structural guarantee," thereby undermining the paper's core claim of robustness.
