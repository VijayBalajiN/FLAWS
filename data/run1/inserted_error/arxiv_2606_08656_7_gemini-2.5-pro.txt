:original_text:
An episode unfolds as $T$ games with interleaved memory updates following Eq.~\ref{eq:memory_update}. The player then uses $m_t$ in game $t+1$. Since the first game serves as initial exploration without learned guidance, we define the episode return as the sum of rewards from the memory-guided games:
\begin{equation}
R(\tau) = \sum_{t=1}^{T-1} r_{t+1},
\label{eq:episode_return}
\end{equation}
where $\tau$ denotes the full trajectory. The training objective is to maximize expected return over opponent strategies $\sigma$ and trajectories $\tau$ generated by the memory policy:
\begin{equation}
\theta^* = \arg\max_\theta \; \mathbb{E}_{\sigma, \tau} \left[ R(\tau) \right].
\label{eq:objective_mdp}
\end{equation}

:modified_text:
An episode unfolds as $T$ games with interleaved memory updates following Eq.~\ref{eq:memory_update}. The player then uses $m_t$ in game $t+1$. Since the first game serves as initial exploration without learned guidance, our goal is to optimize the sequence of memory updates. Because the frozen player $\pi$ is stateless across games and only conditions on the most recent memory $m_t$, the long-horizon problem of maximizing cumulative reward decomposes into a series of independent one-step optimization problems. The objective for turn $t$ is to generate a memory $m_t$ that maximizes the reward of the next game, $r_{t+1}$. The overall training objective is thus to maximize the sum of expected next-game returns across all turns:
\begin{equation}
\theta^* = \arg\max_\theta \; \mathbb{E}_{\sigma, \tau} \left[ \sum_{t=1}^{T-1} r_{t+1} \right].
\label{eq:objective_mdp}
\end{equation}

:original_text:
While Eq.~\ref{eq:objective_mdp} optimizes the cumulative episode return, in practice we estimate turn-level advantages using the one-step outcome $R_{i,t}=r_{i,t+1}$. Using long-horizon returns would couple the learning signal to future stochasticity (e.g., different dealt hands), amplifying environment noise and making credit assignment unstable. The one-step proxy avoids this issue and yields a cleaner turn-wise learning signal, improving stability and sample efficiency for context learning.

:modified_text:
As established in Eq.~\ref{eq:objective_mdp}, our objective is to optimize the memory update at each turn for the outcome of the immediate next game. We therefore define the turn-level return directly as the one-step outcome, $R_{i,t}=r_{i,t+1}$. This formulation is not a proxy; it directly optimizes the objective and avoids confounding the credit assignment with outcomes from future games, which are independent of the current memory update given the stateless nature of the player. This yields a clean, low-variance learning signal perfectly aligned with our decomposed objective.

We ablate reward design to validate our problem formulation. As expected from our analysis in Section~\ref{sec:multi-turn}, optimizing the correctly decomposed one-step objective is substantially more effective. :explanation:
The introduced error is a fundamental mischaracterization of the reinforcement learning problem. The modified text incorrectly claims that the long-horizon memory update problem can be "decomposed into a series of independent one-step optimization problems."

The flawed reasoning is based on the fact that the *player* model is stateless. However, the *memory update process itself* is stateful, as the memory at turn `t` (`m_t`) is a function of the memory at the previous turn `m_{t-1}`. This creates a temporal dependency chain, meaning the decisions are not independent. Optimizing a memory update `m_t` solely for the next game's reward `r_{t+1}` (a myopic objective) can be detrimental to long-term performance. For example, a memory update could learn to make an exploit that works once but reveals the agent's strategy, leading to worse outcomes in subsequent games (`r_{t+2}`, `r_{t+3}`, etc.).

The original paper correctly frames the goal as maximizing the cumulative episode return and uses the one-step reward as a practical, low-variance *proxy* for advantage estimation. The modification changes this to claim that the one-step, myopic reward is the *theoretically correct* objective. This is a subtle but significant conceptual error in RL theory, conflating a practical implementation choice (a biased but low-variance reward signal) with the fundamental problem definition. The error is reinforced across three sections (Method, Training, and Analysis) to make it internally consistent and plausible to a non-expert reader. This error undermines the paper's claim of learning a robust, long-horizon memory mechanism, reframing it as learning a much simpler, myopic one.
