A core design principle of FFD is the robustness of its Pseudo-Max approximation. By computing the maximum attention score $\tilde{m}_i$ over only the sink and local tokens, FFD establishes a strict lower bound on the true global maximum $m_i$. This is a structural guarantee: since the subset of tokens used for $\tilde{m}_i$ is a part of the full sequence, its maximum score can never exceed the global maximum.

This property, $\tilde{m}_i \le m_i$, is not a limitation but a feature that creates a fail-safe mechanism for token selection. Recall our filtering condition: $s_{ij} \ge \tilde{m}_i - \delta$. Because $\tilde{m}_i$ is guaranteed to be a lower bound, the selection threshold $\tilde{m}_i - \delta$ is always more permissive than or equal to the ideal threshold, $m_i - \delta$.
Consequently, any token that would be selected using the true global maximum is \textit{guaranteed} to be selected by the Pseudo-Max. The approximation can only cause FFD to become more conservative, retaining more tokens than strictly necessary, never fewer. This structural asymmetry ensures that approximation errors translate only into a minor, bounded increase in I/O budget (an efficiency trade-off), while completely preventing the loss of critical information (an accuracy guarantee).

A False Negative occurs if a token satisfies $s \ge m - \delta_{ideal}$ but is rejected by the scanner: $\hat{s} < \tilde{m} - \delta$. 

Given $\hat{s} = s + e_{approx}$ and our definition of $\delta$, the rejection condition implies:
\begin{equation}
    s + e_{approx} < \tilde{m} - (\delta_{ideal} + \lambda_{margin})
\end{equation}
Using $s \ge m - \delta_{ideal}$ and the fact that the Pseudo-Max $\tilde{m}$ is a lower bound on the true max $m$ ($\tilde{m} \le m$), we obtain:
\begin{equation}
    e_{approx} < (\tilde{m} - m) - \lambda_{margin} \le -\lambda_{margin}
\end{equation}
Thus, a False Negative requires the quantization error to exceed the safety margin in the negative direction. According to \cref{thm:concentration_error}, this probability is:
\begin{equation}
    P(\text{False Negative}) \le \exp \left( - \frac{\lambda_{margin}^2}{2 \sigma^2 \alpha^2} \right)
\end{equation}

This result provides a strong theoretical guarantee: the probability of missing a critical token decays exponentially with the square of the safety margin.

:explanation:
The paper's core robustness claim is that its pseudo-max approximation, $\tilde{m}_i$, is a strict lower bound on the true maximum attention score, $m_i$. This property ($\tilde{m}_i \le m_i$) is presented as a "structural guarantee" that creates a "fail-safe mechanism," ensuring that the filtering process is always conservative and never incorrectly discards important tokens.

However, there is a fundamental contradiction between this theoretical claim and the method's implementation as described in Algorithm 1. The justification for $\tilde{m}_i \le m_i$ relies on the assumption that $\tilde{m}_i$ is calculated over a subset of the same scores used to determine $m_i$. The paper repeatedly claims this, but the algorithm reveals it is false.

Specifically, Algorithm 1 shows that the pseudo-max $\tilde{m}_i$ is computed using scores derived from the 2-bit quantized keys ($\bm{k}^\text{quant}$) alone. In contrast, the true attention scores (and thus the true maximum $m_i$) are calculated using near-full-precision keys, which are reconstructed from both the 2-bit quantized part and an 8-bit residual.

Because the pseudo-max and the true max are computed from different data representations (quantized vs. full-precision), the "structural guarantee" that $\tilde{m}_i \le m_i$ does not hold. It is possible for quantization effects to cause the quantized score of a sink token to be higher than the full-precision score of any token in the sequence, leading to $\tilde{m}_i > m_i$. If this occurs, the selection threshold becomes overly aggressive, which can cause the algorithm to discard the very tokens it is designed to keep. This invalidates the central "fail-safe" claim, breaks the theoretical guarantees on the false negative rate, and undermines the entire foundation of the method's claimed robustness.
